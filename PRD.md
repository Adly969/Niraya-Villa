# PRD - Niraya Karangasem Villas

---

## 1. Ringkasan Produk

Niraya Karangasem Villas adalah landing page fiktif satu halaman yang dirancang sebagai portofolio pribadi untuk menampilkan kemampuan desain dan pengembangan frontend di segmen luxury hospitality. Halaman ini mensimulasikan website villa premium di Karangasem, Bali Timur, dengan fokus pada visual elegan, copywriting premium, dan user flow yang mengarahkan pengunjung untuk melakukan booking via WhatsApp.

Proyek ini bertujuan membuktikan kemampuan dalam:
- Layout premium untuk niche hospitality
- Responsive design mobile-first
- Copywriting berbahasa Inggris untuk audiens internasional
- CTA booking yang efektif

---

## 2. Background

**Karangasem** adalah kabupaten di ujung timur Bali yang menawarkan karakter berbeda dari Seminyak atau Kuta. Kawasan ini dikenal dengan destinasi budaya seperti Tirta Gangga dan Taman Ujung, pantai tenang seperti Amed dan Candidasa, serta pemandangan Gunung Agung yang ikonik.

Bali Timur masih relatif sepi dibanding Bali Selatan, menjadikannya pilihan ideal untuk traveler yang mencari pengalaman autentik, tenang, dan jauh dari kerumunan turis massal.

Landing page ini dibuat sebagai portfolio frontend untuk menunjukkan kemampuan membuat situs hospitality yang terlihat realistis, premium, dan layak digunakan secara nyata.

---

## 3. Tujuan Project

- Menampilkan villa secara visual premium dengan foto berkualitas tinggi
- Mengarahkan user untuk melakukan booking via WhatsApp (CTA utama)
- Menampilkan fasilitas, tipe villa, galeri, lokasi, dan pengalaman menginap
- Menjadi portofolio landing page yang terlihat realistis, profesional, dan layak dipakai klien nyata

## 4. Target Audience

### 4.1 Honeymoon Couple
- **Usia:** 25–38 tahun
- **Kebutuhan:** Suasana romantis, privasi, kolam renang pribadi, pelayanan personal
- **Pain point:** Villa umum terlalu ramai, tidak ada suasana intim
- **Yang dicari:** Private pool, pemandangan tropis, layanan honeymoon setup

### 4.2 Family Traveler (Keluarga Kecil)
- **Usia:** 30–45 tahun
- **Kebutuhan:** Ruang yang cukup, aman untuk anak, aktivitas lokal dekat
- **Pain point:** Villa mewah seringkali tidak child-friendly
- **Yang dicari:** Villa dengan ruang luas, dapur atau kitchenette, area outdoor aman

### 4.3 International Tourist
- **Asal:** Eropa, Australia, Amerika, Asia Timur
- **Kebutuhan:** Booking mudah, informasi lengkap dalam bahasa Inggris, kepercayaan
- **Pain point:** Susah menemukan villa autentik yang tidak terlalu komersial
- **Yang dicari:** Pengalaman Bali yang otentik, budaya lokal, alam yang asri

### 4.4 Remote Worker / Workcation
- **Usia:** 26–40 tahun
- **Kebutuhan:** WiFi stabil, meja kerja, suasana tenang, durasi menginap lebih panjang
- **Pain point:** Hotel/villa touristy terlalu ramai untuk fokus bekerja
- **Yang dicari:** Ketenangan, koneksi internet, nuansa produktif namun tetap santai

### 4.5 Luxury Slow Traveler
- **Usia:** 35–55 tahun
- **Kebutuhan:** Pengalaman mendalam, tidak terburu-buru, koneksi dengan budaya lokal
- **Pain point:** Paket wisata terlalu padat, villa terlalu modern tanpa karakter lokal
- **Yang dicari:** Heritage, autentik, alam, kuliner lokal, destinasi budaya dekat villa

## 7. Detail Setiap Section

### 7.1 Navbar
- **Tujuan:** Navigasi halaman dan identitas brand
- **Konten:** Logo teks "Niraya", menu (About, Villas, Gallery, Experience, Contact), tombol "Book Now"
- **Komponen:** Sticky navbar, transparent saat di top → putih/cream setelah scroll
- **Responsive:** Hamburger menu di mobile

### 7.2 Hero Section
- **Tujuan:** First impression premium, capture perhatian dalam 3 detik
- **Konten:** Background foto full screen pool/villa, overlay gelap, tagline utama, 2 CTA button
- **Komponen:** Full-screen image, overlay gradient, heading H1, subheading, 2 button
- **CTA:** "Explore Villas" + "Book via WhatsApp"
- **Responsive:** Text lebih kecil di mobile, button stacked vertical

### 7.3 About Villa
- **Tujuan:** Membangun kepercayaan dan karakter brand
- **Konten:** Foto villa + teks deskripsi singkat, poin keunggulan, angka statistik (misal: "3 private villas", "Est. 2019", "100+ happy guests")
- **Komponen:** 2-column layout (image kiri, teks kanan), highlight stats
- **Responsive:** Stacked di mobile

### 7.4 Villa Highlights
- **Tujuan:** Menampilkan fasilitas unggulan secara ringkas
- **Konten:** Icon + teks untuk: Private Pool, Tropical Garden, Outdoor Shower, Daily Breakfast, Airport Transfer, 24hr Concierge
- **Komponen:** Grid 3-kolom icon cards
- **Responsive:** 2 kolom tablet, 2 kolom mobile

### 7.5 Villa Types
- **Tujuan:** Utama — menampilkan pilihan villa dan harga
- **Konten:** 3 kartu villa dengan foto, nama, kapasitas, fasilitas, harga, CTA
- **Komponen:** Card dengan image, badge harga, list fasilitas, button "Inquire Now"
- **CTA:** "Inquire Now" → buka WhatsApp
- **Responsive:** 1 kolom di mobile, scroll horizontal atau stacked

### 7.6 Nearby Destinations
- **Tujuan:** Meningkatkan daya tarik lokasi
- **Konten:** Tirta Gangga, Taman Ujung, Amed Beach, Candidasa, Pura Lempuyang — 5 kartu dengan foto + jarak dari villa
- **Komponen:** Horizontal scroll card di mobile, grid 5 kolom di desktop
- **Responsive:** Horizontal scroll di mobile

### 7.7 Gallery
- **Tujuan:** Visual selling — tunjukkan estetika villa
- **Konten:** 8–10 foto villa, pool, kamar, sarapan, pemandangan, aktivitas lokal
- **Komponen:** Masonry grid atau 3-kolom grid, hover overlay tipis
- **Responsive:** 1 atau 2 kolom di mobile

### 7.8 Experience Section
- **Tujuan:** Menjual "lifestyle", bukan hanya kamar
- **Konten:** 3–4 item pengalaman: Morning Yoga by the Pool, Cultural Day Trip, Private Dining, Sunset Terrace
- **Komponen:** Large image card dengan teks overlay
- **Responsive:** Stacked di mobile

### 7.9 Booking Form Dummy
- **Tujuan:** Simulasi booking, dummy tanpa backend
- **Konten:** Field: Check-in, Check-out, Guests, Villa Type, tombol "Check Availability"
- **Komponen:** Card form dengan shadow, input rounded
- **CTA:** Tombol → alert atau redirect ke WhatsApp
- **Responsive:** Stacked vertical di mobile

### 7.10 Testimonials
- **Tujuan:** Social proof
- **Konten:** 3 testimoni dummy dari tamu internasional
- **Komponen:** Card testimoni dengan nama, asal negara, bintang, kutipan
- **Responsive:** 1 kolom mobile, 3 kolom desktop

### 7.11 Final CTA
- **Tujuan:** Last chance conversion
- **Konten:** Kalimat ajakan + 2 tombol (WhatsApp + Email)
- **Komponen:** Full-width section dengan background gelap atau foto overlay

### 7.12 Footer
- **Konten:** Logo, tagline, menu navigasi, sosial media dummy, copyright
- **Komponen:** 3-kolom layout (brand, nav, contact)
- **Responsive:** Stacked di mobile

### 7.13 Sticky WhatsApp Button
- **Posisi:** Fixed bottom-right
- **Warna:** Hijau WhatsApp atau disesuaikan brand
- **Komponen:** Icon + tooltip "Chat with Us"

## 10. Fitur Landing Page

**Wajib:**
- Responsive layout (mobile-first)
- Smooth scroll antar section
- Sticky navbar (transparent → solid setelah scroll)
- Sticky WhatsApp floating button
- Booking form dummy
- Gallery masonry/grid
- Destination cards
- Villa type cards dengan harga
- CTA button di setiap section strategis
- Testimonial cards

**Opsional:**
- Fade-up animation saat scroll
- Hover effect pada card (lift + shadow)
- Image overlay gradient
- Scroll reveal ringan
- Slow zoom pada hero image

## 13. Technical Requirement

**Rekomendasi stack:**
- HTML5 + CSS3 + JavaScript vanilla (paling ringan untuk portofolio)

- Gambar dari Unsplash (via URL langsung atau didownload)

## 14. Non-Functional Requirement

| Aspek | Detail |
|-------|--------|
| Performance | Gambar dioptimasi, lazy loading, tidak ada library berat |
| Accessibility | Alt text semua gambar, kontrast warna memadai, label form jelas |
| SEO | Meta title/description, struktur heading benar, semantic HTML |
| Mobile-first | CSS dimulai dari breakpoint mobile, lalu scale ke atas |
| Clean code | Komentar section, penamaan class konsisten (BEM atau Tailwind) |
| Maintainability | Mudah diubah konten tanpa harus redesign |

## 16. Risiko dan Batasan

| Risiko | Mitigasi |
|--------|----------|
| Ini bukan sistem booking asli | Form dummy, arahkan ke WhatsApp |
| Data harga dummy | Label "start from" dan disclaimer kecil |
| Testimoni fiktif | Label "Guest Reviews" tanpa nama asli yang bisa diverifikasi |
| Tidak ada backend | Semua interaksi di client-side |
| Animasi terlalu berat | Batasi pada fade-up ringan, tidak ada parallax berat |
